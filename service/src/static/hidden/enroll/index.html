This installs a certificate that lets this device open Carburantes. Choose a password for the certificate file. You only need it once, when you import the file.

The link works only once. If the download fails, ask for a new one.

has been downloaded. Import it with the password you just chose:

Android
  1. Settings → Security → Encryption & credentials → Install a certificate → VPN & app user certificate.
  2. Pick the downloaded file and enter the password.
iPhone / iPad
  1. Open the downloaded file from Files. It gets added as a profile.
  2. Settings → General → VPN & Device Management → install the profile and enter the password.
Windows / macOS (Chrome, Edge, Safari)

Double-click the file and follow the import wizard (on macOS it goes into the login keychain).

Firefox

Settings → Privacy & Security → Certificates → View Certificates → Your Certificates → Import.

Then restart the browser and open Carburantes. When the browser asks, pick this certificate.
